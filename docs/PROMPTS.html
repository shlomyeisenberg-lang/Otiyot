Otiyot Playbook

אותיות · a 3D typing adventure. 39 tasks, one chat each. The scheduled builders use the same prompts on their own; this page is for when you want to run one yourself or need a helper prompt.

Rules for every task: no women and nothing sexy anywhere (all human characters male); text to type uses only letters the player has already learned, and every scene has Easy / Standard / Hard levels that unlock with course progress. They are written in CLAUDE.md, which every prompt reads first.

How to use it

  1. Start a new chat with the Otiyot repo attached.
  2. Pick the model shown on the card, paste the next prompt.
  3. Read the short plan, reply OK.
  4. When it says merged, try it on the live link and tick the card.

Which model

ModelUse for
Fable 5.2Anything that needs taste and skill: the look, 3D scenes, game feel, story, music, bosses.
Sonnet 5.5Mechanical work: setup, carrying over the old lessons and games, saves, tests, packaging. If Sonnet gets stuck twice, continue the task with Fable.
Haiku 5.5Quick read-only questions such as "Where are we?".

Accounts you need

GitHub (you have it) and Vercel for the live link (after T01; the task gives you a ready prompt for Claude in Chrome). Nothing else: no database, no keys.
